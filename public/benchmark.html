WHY C++ / WASM WINS

The LSB embedding loop touches every byte of the image. In JavaScript, each array access goes through the JS engine's type checking and bounds checking. In C++ compiled to Wasm, it's a direct memory operation — no overhead. For megapixel images this compounds to a significant difference.

HOW IT'S MEASURED

Both implementations perform identical work: generate a random payload of the selected size, then embed it into a synthetic 1024×1024 RGBA image using std::mt19937 PRNG scatter (Wasm) or the equivalent LCG in JS. Timing uses performance.now() around the core loop only — no I/O.
