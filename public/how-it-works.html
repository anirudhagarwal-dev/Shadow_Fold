01
CARRIER IMAGE UPLOAD
You provide a cover image — PNG or BMP. This is the "right side up" world. The image is drawn onto an HTML5 Canvas which exposes raw RGBA pixel data as a flat byte array. Every pixel has 4 channels: Red, Green, Blue, Alpha.
canvas.getImageData() → Uint8Array [R,G,B,A, R,G,B,A, ...]
1920×1080 image = 8,294,400 bytes of raw pixel data
02
SECRET FILE SERIALIZATION
Your secret file — any type — is read as raw bytes. A header is prepended with a magic signature, filename length, filename, and data length. This ensures perfect reconstruction during decode, preserving the original file format and name.
Header: SHDW (4B) + name_len (4B) + filename + data_len (4B) + raw_bytes
Max payload capacity = width × height × 3 / 8 bytes
03
PASSWORD-SEEDED PRNG SHUFFLE
Your password is hashed using FNV-1a into a 32-bit seed. That seed initialises a Mulberry32 PRNG, which performs a Fisher-Yates shuffle over all pixel indices — producing a unique, deterministic scramble only reproducible with the exact password. Even if an attacker knows LSB was used, without the password they cannot determine which pixels to read.
FNV-1a(password) → 32-bit seed → Mulberry32(seed)
Fisher-Yates over N pixels → unique pixel order[]
04
LSB STEGANOGRAPHY ENCODING
Each bit of the payload is written into the Least Significant Bit of an R, G, or B channel of a pixel selected by the PRNG order. Changing only the LSB shifts a colour value by at most ±1 — completely imperceptible to the human eye. The Alpha channel is never modified.
pixel[i] = (pixel[i] & 0xFE) | bit
255 → 254 or 255  ·  visual change: < 0.4% per channel
05
LOSSLESS PNG EXPORT
The modified pixel array is written back to the canvas and exported as PNG — a lossless format that preserves every pixel exactly. JPEG must never be used: its lossy compression would corrupt the LSB bits and destroy the hidden data entirely.
canvas.toBlob('image/png') → lossless stego image
Visual difference from original: undetectable
Glowing pixels have been modified by LSB encoding. The corner bit shows what was injected.
🔐
SECURITY MODEL
Shadow Fold provides steganographic security, not cryptographic encryption. The password controls which pixels carry the data via PRNG — without it, the data is unreadable even if its presence is suspected. For maximum security, encrypt your file before hiding it. A future AES-256 layer is planned.
